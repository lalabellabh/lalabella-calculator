Lalabella on PC / Mac

Install Lalabella as an app on the shop computer: its own window and icon, opens by itself, and rings when a new order comes in.

Use Google Chrome or Microsoft Edge to install. Safari and Firefox cannot install it as an app with alerts.

1 · Install

  1. Open mysystemlla.com in Chrome or Edge and log in.
  2. Click the Install icon at the right end of the address bar (or the button above, or menu ⋮ → Cast, save and share → Install page as app in Chrome; … → Apps → Install this site as an app in Edge).
  3. Keep Create shortcut ticked so it gets a desktop icon, then Install.

2 · Open by itself when the PC starts

  1. Easiest way (always works on Windows): press Win + R, type shell:startup, Enter.
  2. Copy the Lalabella desktop icon into that folder.
  3. Edge also has it in edge://apps → Lalabella → Start app on device sign-in.

3 · Alerts and sound

  1. Click Allow when asked for notifications (or turn on in ☰ → ⚙️ Settings → Notifications (this device)).
  2. There you can choose 💬 Chat and 🛍️ New orders separately, and use Send test.
  3. In ⚙️ Settings → New-order alert sound set the volume (0 = silent). The ring repeats until you click the pop-up.
  4. After opening the app, click anywhere once. The browser only allows sound after one click.
A computer that is asleep or shut down cannot receive alerts. In Windows set Settings → System → Power → Screen and sleep to Never for the shop PC, and keep it signed in to Lalabella. Your phone still gets the notification.
